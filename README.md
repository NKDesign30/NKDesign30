I build software where design, AI, automation, and real product workflows meet.

My main focus is **NEON**: an agent ecosystem for getting work done with memory, tooling, approvals, quality gates, Discord workflows, local files, native apps, and public-safe automation.

Some of the most interesting work is private by design. The public repos here are the safe surface area: frameworks, native app tooling, MCP servers, and product infrastructure.

## What I build

| Area | Focus |
| --- | --- |
| Agent systems | Multi-agent workflows, memory, approvals, tool orchestration, autonomous research and execution |
| Product engineering | TypeScript, Next.js, React, Node.js, Swift, macOS apps, MCP, APIs, automation |
| AI workflows | Prompt systems, demo preparation, sales material, documentation, voice and meeting tooling |
| Robotics enablement | Event prompts, product knowledge, customer-facing demos, and internal workflows for physical AI products |
| Design systems | Fast, sharp, usable product surfaces with a strong visual identity |

## Current direction

- Building NEON as an operating layer for AI-assisted work.
- Turning agent workflows into real products, not demos.
- Connecting local-first tools, memory, design, and automation into one usable system.
- Applying the same stack to robotics demos, sales enablement, and customer-specific knowledge workflows.
